3. Presentación institucional

Este documento desarrolla la arquitectura inicial del Manual Interno de Organización, Procedimientos y Comunicación entre Gerencias de ECAR. Su finalidad es definir el índice completo del manual, el mapa general de procesos, la clasificación de procesos, la lógica de comunicación entre áreas y los criterios mínimos para que cada procedimiento posterior tenga una estructura homogénea, exigible y útil para la conducción.

La mejora de esta versión no busca desarmar lo ya realizado. Busca normalizar la presentación, fortalecer el enfoque de procesos, mejorar la lectura del documento y preparar una base común para los procedimientos de Proyectos y Presupuestos, Compras, Logística, Obras y futuras áreas de apoyo.

Los apuntes previos de Logística y Obras se consideran antecedentes conceptuales. Los documentos definitivos deberán integrarse dentro de este sistema, respetando la misma estética, la misma lógica de trazabilidad, el mismo tamaño de letra y el mismo enfoque compatible con criterios de gestión de calidad tipo ISO 9001.

4. Objetivo del manual

Instalar en ECAR una forma de trabajo más ordenada, trazable y medible, reduciendo la gestión por urgencias, memoria, mensajes aislados o decisiones improvisadas. El manual debe ayudar a que cada gerencia conozca qué recibe, qué debe transformar, qué debe entregar, con qué evidencia, a quién debe comunicar y bajo qué indicadores será revisada.

Ordenar el funcionamiento entre gerencias y reducir superposiciones.

Definir procesos, responsabilidades, registros, indicadores y criterios de escalamiento.

Convertir la comunicación interna en un sistema de trabajo con evidencia, no sólo en mensajes de WhatsApp.

Mejorar la toma de decisiones de Gerencia General mediante reportes, indicadores y registros mínimos.

Preparar a ECAR para crecer con mayor estructura, control operativo y mejora continua.

6. Criterio rector del sistema de gestión

Cada gerencia debe saber qué recibe, qué transforma, qué entrega, a quién se lo entrega, con qué evidencia y bajo qué criterio será evaluada.

El manual no debe ser una carpeta decorativa. Debe convertirse en una herramienta de conducción: sirve para ordenar, exigir, medir, corregir y mejorar. La empresa debe poder revisar sus procesos con evidencia y no depender solamente de la memoria de las personas o de conversaciones informales.

7. Principios compatibles con ISO 9001

El documento utiliza criterios compatibles con gestión de calidad tipo ISO 9001. Esto no significa declarar certificación formal, sino adoptar una lógica práctica de procesos, información documentada, control operativo, riesgos, indicadores y mejora continua aplicada a la realidad de ECAR.

Principio

Aplicación práctica en ECAR

Enfoque a procesos

Cada área se define por entradas, actividades, salidas, responsables, evidencias y medición.

Liderazgo

Gerencia General conduce el sistema, define prioridades y evita absorber todas las decisiones operativas.

Planificación

Las obras, compras y recursos deben anticiparse; la urgencia no puede ser el modo normal de trabajo.

Pensamiento basado en riesgos

Cada etapa identifica riesgos de plazo, costo, calidad, seguridad, abastecimiento y cliente.

Información documentada

Lo importante debe quedar registrado: pedido, aprobación, entrega, desvío, decisión y cierre.

Control operativo

Los procesos deben tener criterios mínimos antes de avanzar: datos completos, aprobación, recepción, ejecución y cierre.

Evaluación del desempeño

Cada gerencia debe tener indicadores simples, útiles y revisables por Gerencia General.

No conformidad y acción correctiva

Los desvíos se registran para corregir causas, no para acumular culpas.

Mejora continua

Cada cierre de obra o etapa debe dejar aprendizajes que actualicen procesos, plantillas y decisiones.

9. Mapa general de procesos entre gerencias

El mapa general permite entender el recorrido completo de la gestión: desde la oportunidad o necesidad inicial hasta el cierre, evaluación y mejora. La empresa debe funcionar como un sistema encadenado, no como áreas aisladas. Una falla de información en Proyectos puede generar una mala compra; una mala compra puede generar un problema logístico; una falla logística puede frenar Obras; una mala ejecución puede afectar costos, cliente e imagen institucional.

15. Perfiles, alcances y herramientas por gerencia

A partir de esta versión, cada procedimiento deberá incorporar el perfil del responsable del puesto, el alcance de la persona que ocupa el puesto y las herramientas necesarias para cumplir la función. El procedimiento define cómo debe funcionar el área; el perfil define qué capacidades debe tener la persona responsable para sostener ese funcionamiento.

No se debe exigir control sin herramientas. Cada responsable debe contar con los medios físicos, tecnológicos, documentales y de gestión necesarios para cumplir su función con orden, evidencia y trazabilidad.

17. Cierre institucional y nota normativa

Este primer documento define la columna vertebral del futuro manual. El objetivo no es agregar papeles, sino instalar una forma de trabajar: procesos claros, responsabilidades visibles, comunicación ordenada, registros mínimos, indicadores útiles, tratamiento de desvíos y mejora continua.

ECAR crecerá con mayor solidez cuando cada gerencia pueda responder con claridad: qué debe hacer, qué debe entregar, qué debe registrar, cuándo debe comunicar, qué herramientas necesita y cómo debe corregir sus desvíos.

Nota normativa de referencia: este documento utiliza criterios compatibles con gestión de calidad tipo ISO 9001, sin declarar certificación formal. La referencia se emplea como marco de ordenamiento documental, trazabilidad, control operativo y mejora continua. Toda actualización normativa futura deberá revisarse para ajustar el manual si corresponde.
