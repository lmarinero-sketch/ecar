# Instrucciones Generales para Antigravity

**REGLA CRÍTICA:**
Siempre, ante cualquier nueva tarea o requerimiento que pida el usuario, debes **REVISAR PRIMERO** la carpeta de skills (`.skills` o la ubicación donde estén instaladas) para ver si existe alguna skill o guía que aplique a la situación o tecnología solicitada. 

**Flujo Obligatorio:**
1. Recibes la solicitud del usuario.
2. Analizas las skills disponibles (usando búsqueda o leyendo el directorio de skills).
3. Si encuentras una skill relevante, la lees detalladamente y aplicas sus patrones y sugerencias.
4. Si no encuentras nada relevante, procedes de manera habitual.
5. No asumas ni ejecutes comandos sin antes validar si hay una skill que te marque el camino preferido por el equipo.
